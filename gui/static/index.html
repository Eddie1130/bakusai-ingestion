新增店家

三步，開始使用。

  1. 新增或選擇店家

    搜尋會連線至 Bakusai。看過抓取計畫並確認後，才開始抓取留言。

  2. 產生並複製提示詞

    選擇名字、特徵或全店整理，將提示詞貼給你慣用的模型。字數與 tokens 粗估會一併顯示。

  3. 貼回報告、核對原文

    在「報告與引用」貼回結果。引用會區分為範圍內、期間外、未送出與不存在。

資料與報告請保留於個人研究用途。報告不會自動儲存，重新整理頁面前請自行保留需要的內容。
